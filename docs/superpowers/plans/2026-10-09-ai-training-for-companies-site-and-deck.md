# AI Training For Companies: Site and Deck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Next.js site at `~/consulting` for AI Training For Companies with five case studies, an eight-week program page, a contact form, SEO/AEO metadata, and a 14-slide cold-outbound deck at `/deck`, all in one engineering-notebook design system.

**Architecture:** App Router site with all copy in typed content files under `src/content/`. Presentational components under `src/components/` read content and never hardcode copy. The deck is a client component at `/deck` that renders the same case-study content as the site, navigates by URL hash, and prints one slide per page. Contact form posts JSON to `/api/contact`, validated by a pure function in `src/lib/`, delivered by nodemailer.

**Tech Stack:** Next.js 16.2 (App Router), React 19, TypeScript strict, Tailwind CSS 4 (PostCSS), IBM Plex Sans + Mono via `next/font/google`, nodemailer, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-09-ai-training-for-companies-site-and-deck-design.md`

**Decisions from spec review:**
- Pricing renders a single cohort option. No invented tiers. A one-line note says follow-on advisory is quoted per engagement.
- Deck slide index lives in the URL hash (`/deck#7`). Without JavaScript the page is a scrollable list of slides.
- Contact route returns 503 with a generic message in production and in dev when SMTP env is missing; dev additionally logs the lead to the console.
- OG image is typographic, generated by `src/app/opengraph-image.tsx` using the design tokens.
- Copy for deck slides 11 and 13 and the program outcomes is drafted from the positioning section and flagged in the final report for Jordan's review.
- The deck is a cold-outbound asset, not a landing page: `/deck` is `noindex` and disallowed in `robots.txt`.
- Route groups from the start: `src/app/layout.tsx` keeps `<html>/<body>`, fonts, and `metadataBase`; `src/app/(site)/layout.tsx` adds Nav and Footer; all site pages live under `src/app/(site)/`; `src/app/deck/page.tsx` sits outside the group so it renders without Nav and Footer.
- `src/content/site.ts` is created in Task 1 because the root layout reads `site.url` for `metadataBase`.
- Title template is `%s | AI Training For Companies`. Per-page titles are bare (`About Jordan Millhausen`, `Contact`). Home uses `title: { absolute: ... }`. Every page sets `alternates.canonical`.
- The FAQ must include these three questions verbatim: "What is a forward deployed engineer?", "How much does AI training for a company cost?", "How long does it take to train an AI engineer?".
